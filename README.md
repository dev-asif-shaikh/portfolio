# Interactive Developer Portfolio

An interactive, responsive single-page application (SPA) developer portfolio built with React 18, Vite, and Bootstrap 5. Designed with inspiration from the modern React.js documentation visual identity.

![Vite](https://img.shields.io/badge/Vite-latest-646CFF?style=for-the-badge&logo=vite)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5.x-7952B3?style=for-the-badge&logo=bootstrap)

---

## Features

- React.dev Inspired Aesthetic: Dark (Obsidian) and Light Mode context theme switcher built with React Context API (ThemeContext).
- Interactive Hero Stage: 3D perspective mouse-tilt hover effect with an automated revolving React logo cursor on pointer pause.
- Auto-Sliding Project Carousel: Displaying deployed prototypes with custom hover glow triggers and responsive viewports.
- Centralized Profile Control Panel: Decoupled ProfileData.js configuration system allowing instant updates to current availability status and active learning tech stacks.
- Fully Responsive Layout: Built using custom clamp() fluid typography scales and container-wide flex wrappers for edge-to-edge widescreen layout presentation.

---

## Tech Stack & Libraries

- Frontend Library: React 18
- Build Tool: Vite
- Styling & UI: Bootstrap 5, Custom CSS3 Variables
- Routing: React Router (BrowserRouter)
- State Management: React Context API (useContext, useState, useEffect)
